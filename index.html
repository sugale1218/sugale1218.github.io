AI-Driven Terraform Misconfiguration Scanner

MSc Dissertation · University of East London

Trained and compared Logistic Regression, Random Forest, and XGBoost classifiers on 480 real-world Terraform files spanning six AWS resource types to detect misconfigurations from TF-IDF text features. XGBoost outperformed a rule-based baseline, confirmed via 5-fold cross-validation (mean 95.43%). A second classifier assigns graded LOW / MEDIUM / HIGH severity scores at 94.57% accuracy.

Packaged both models into a scanner deployed inside a GitHub Actions CI/CD pipeline that automatically scans pull requests touching Terraform files and blocks merges on detected HIGH-severity issues — validated against a real pull request containing a deliberately introduced misconfiguration.
